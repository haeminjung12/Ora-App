
# Example HEP Prescriptions
## HEP #1 — Jaw Mobility / Trismus Track (Gaming + optional Video)
**Target population:** trismus / reduced mouth opening / jaw stiffness (SLP decides appropriateness)  
**Goal (clinical):** improve functional jaw mobility (clinician measures separately)

### A) Gaming mode (jaw reps)
- **Frequency:** 5 days/week
- **Duration:** 12 minutes/session
- **Structure:** 3 blocks × 4 minutes, 60–90 sec rest between blocks
- **In-app goals (loggable only):**
  - session duration ≥ 12 min
  - open/close events ≥ 120 total
  - lateral events ≥ 60 total (balanced L/R within 20%)
  - consistency score ≥ threshold (optional; define with therapist)
- **Stop rules (therapist-defined):**
  - pain > X/10, jaw locking/clicking increases, headache, dizziness, etc.

### B) Video mode (instruction + completion)
- **Frequency:** 2 days/week
- **Content:** therapist-selected jaw stretch instruction video(s)
- **Goal (loggable):** completion ≥ 90% (tracking-quality flags only)

### What the report shows (weekly)
- adherence: sessions completed / scheduled
- median duration
- total events (open/close, lateral) + L/R balance
- missed sessions + “tracking quality” flags

## HEP #2 — Dysphagia Support / Adherence Track (Video-first)
**Target population:** dysphagia patients doing clinician-prescribed maneuvers (CTAR/Shaker/Mendelsohn/etc.)  
**Goal (clinical):** adherence support + reminders; clinician evaluates technique separately

### Video mode (instruction + completion)
- **Frequency:** 5 days/week
- **Duration:** 10 minutes/session
- **Content:** therapist-assigned videos for the exact maneuvers they prescribe
- **In-app goals (loggable only):**
  - completion ≥ 90%
  - tracking quality ≥ threshold (so SLP can interpret “did they watch/do it” vs “camera lost them”)
- **Stop rules:** therapist-defined (fatigue, neck pain, coughing, etc.)

### Optional Gaming add-on (only if SLP wants jaw activity in plan)
- **Frequency:** 2 days/week
- **Duration:** 6 minutes/session
- **Purpose:** jaw mobility/cadence only (NOT swallow training)
- **Loggable:** duration + event counts only

### What the report shows (weekly)
- adherence trend (sessions completed / scheduled)
- completion %
- tracking-quality flags
- notes field for patient/caregiver (optional)
